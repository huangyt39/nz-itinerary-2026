# 新西兰南岛 2026 行程

2026.09.23 – 10.06｜香港 → 悉尼 → 基督城 → 但尼丁 → 皇后镇 → 瓦纳卡 → 库克山 → 蒂卡波 → 凯库拉 → 墨尔本 → 香港

一个单页静态行程网站，包含五个分区：

- **行程亮点**：路线地图、核心数据、亮点卡片
- **每日行程**：14 天逐日叙事（含交通、住宿、营业时间提示）
- **费用与预订**：人均预算构成与逐项明细、预订状态
- **南岛预习**：出发前需要了解的自驾、天气、观星、野生动物等要点
- **行前清单**：证件、飞行包、衣物、药品、摄影等 75 项，勾选状态保存在浏览器本地

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 技术说明

- 纯静态单文件页面（`index.html`，内联 CSS / JS），无构建步骤
- 地图使用 Leaflet + OpenStreetMap 瓦片（`vendor/`）
- 图标使用 Lucide
- 清单勾选进度通过 `localStorage` 保存
